# DevVoice

AI speaking coach for engineers. Speak, get feedback, improve.

## Problem
Engineers know the tech but struggle to explain it clearly in
interviews, standups, and meetings.

## Planned Features
- [ ] Explain Mode: explain a concept, get a clarity score
- [ ] Interview Mode: questions based on your own GitHub repo
- [ ] Standup Mode: 60-second update practice
- [ ] Feedback: filler words, pace, grammar, confidence
- [ ] Progress dashboard

## Tech Stack
Python, FastAPI, PostgreSQL, Whisper, Claude API, Streamlit, Docker
